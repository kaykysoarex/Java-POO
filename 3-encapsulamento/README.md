# Encapsulamento

## Conteúdo estudado

Este diretório contém o conteúdo de **encapsulamento em Java**, um dos princípios da Programação Orientada a Objetos (POO).

O encapsulamento permite proteger os atributos de uma classe e controlar como eles podem ser acessados ou modificados.

### Conceitos estudados

- `private`: restringe o acesso direto aos atributos.
- `public`: permite acesso externo aos membros públicos.
- **Getters:** métodos utilizados para consultar atributos.
- **Setters:** métodos utilizados para modificar atributos de forma controlada.

### Objetivo do conteúdo

Compreender como proteger os dados de uma classe, evitar alterações indevidas e controlar o acesso aos atributos por meio de métodos.
